| Pin | Costura | Tarea |

Todo es `software/web`: sin endpoint nuevo ni cambiado, `openapi.json` no cambia, por eso no hay tarea de prueba HTTP
real del backend (los endpoints ya los cubren las pruebas Pest de identity-access y catalog). Backend y devops no
participan; un solo implementador (frontend). Sin `design.md`: no hay costura nueva (tabla única de pantallas,
`RequireAbility`, `useSubmitGuard`, `SubmitButton`, `ErrorMessage`, `fieldErrors`, `PageHeader`, kit shadcn).

Pruebas: Vitest + Testing Library, red simulada con MSW en el borde HTTP (`src/test/http.ts`; nunca se simula el hook
ni el componente bajo prueba), primero en rojo, luego el código. El título de cada prueba nueva o renombrada empieza
por el título literal de su escenario: los filtros `-t` de los `[MUT]` son ese título. Archivos de prueba, relativos a
`software/web/`: `src/features/users/users-page.test.tsx`, `src/features/catalog/catalog-page.test.tsx`,
`src/features/assistant/assistant-page.test.tsx`, `src/app/require-ability.test.tsx`. Textos solo desde
`src/lib/strings.ts`; colores solo por tokens de tema (S12). Escenarios citados como «Requisito: escenario» de
`specs/<capacidad>/spec.md`. Presupuesto de suite (tier B): corridas delta por archivo más **una** corrida completa de
cierre (6.1). Orden: 0 → 1 → 2 → 3 → 4 → 5 → 6.

**Convención `[MUT]`** (comando autocontenido, bash o zsh, desde la raíz del repo). Precondición: la tarea de commit del
bloque (2.3, 3.4, 4.6) dejó el árbol verde confirmado en `dev` y `git status --porcelain -- software/web` vacío; el
comando lo vuelve a exigir antes de aplicar el parche. El parche
`openspec/changes/add-admin-screens/mutants/Mn.patch` es el diff de una sola costura. El comando aplica el parche,
corre la prueba filtrada (debe FALLAR con al menos una prueba fallida), revierte, la corre de nuevo (debe PASAR con al
menos una prueba pasada: `vitest -t` sin coincidencias sale 0 y no cuenta) y exige árbol limpio. Sale 0 solo si todo
se cumple. Fila en `verification.md`: `| n | mutación | Aplicado → FALLA m/k: prueba | Restaurado → PASA k/k |`.
