# Tailwind CSS + shadcn/ui for the React UI

Screens are operational (tables, forms, dialogs, toasts) for a fast-paced pharmacy environment, built in a
6–8 hour budget. shadcn/ui copies accessible components into the repo (no runtime dependency, full control
over copy and states) and Tailwind keeps styling local to components. The harness already carries the
`shadcn`, `accessibility` and `web-design-guidelines` skills.

Considered: Mantine (complete but a runtime dependency, no skill support); plain CSS (more hours on tables
and dialogs). All user-facing strings live in one Spanish strings module regardless of kit.
