# Tailwind CSS + shadcn/ui para la interfaz React

Las pantallas son operativas (tablas, formularios, diálogos, avisos) para un entorno de farmacia de ritmo
rápido, construidas con un presupuesto de 6–8 horas. shadcn/ui copia componentes accesibles al repo (sin
dependencia en tiempo de ejecución, control total sobre textos y estados) y Tailwind mantiene los estilos
junto a cada componente. El harness ya incluye las skills `shadcn`, `accessibility` y
`web-design-guidelines`.

Considerado: Mantine (completo, pero dependencia en tiempo de ejecución y sin skill); CSS propio (más horas
en tablas y diálogos). Todas las cadenas visibles viven en un único módulo de textos en español, sin importar
el kit.
