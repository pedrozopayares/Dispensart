# Pest over plain PHPUnit for the backend suite

Both are accepted by the test and share the PHPUnit engine. Pest is chosen for `arch()` tests, which turn
"business logic lives outside controllers" (test part A) into an executable rule, plus datasets and parallel
runs with less boilerplate. The last-unit concurrency test (RN-03) is equally hard in either: real parallel
connections, PostgreSQL, no `RefreshDatabase` transaction wrapper.

Considered: PHPUnit alone — more familiar to more readers, loses `arch()`. Revisit if a Pest major breaks
Laravel 13 compatibility mid-test.
